# 接口适配记录 002

日期：2026-09-07。目标面板为浏览器实际显示的 v2.21.0。

## 本次修复

- 登录页增加账号密码/应用密钥切换；登录、历史账号切换和 Token 保存统一传递登录方式，应用模式使用 `/open` 路径。
- 二次验证不携带旧 Token；应用密钥模式不调用账号信息接口，账号专属设置提示改用账号登录。
- 任务列表使用 `searchValue`，移除固定 10000 条上限；服务端不传 page/size 时返回完整列表。仍沿用客户端内存过滤，大数据量场景需要后续分页。
- 日志文件名按 URL 段编码，目录通过 query 参数传递，保留空格、中文、`#` 和 `&`。
- 日志设置版本分支：2.15.16 及以前 `/system/log/remove` + `frequency`；2.15.17–2.16.5 GET/PUT `/system/config` + `logRemoveFrequency`；2.17.0 起 PUT `/system/config/log-remove-frequency`。读取支持旧、新字段。
- 版本比较按数字段处理，支持 v 前缀和版本后缀；HTTP 非 JSON 错误保留状态码，不打印 Dio 请求异常。
