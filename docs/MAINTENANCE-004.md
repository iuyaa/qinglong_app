# 稳定性与 App 更新 004

目标版本 3.0.4。本轮使用合成数据及已保留的青龙 v2.21.0 源码核对，没有连接真实面板，也没有修改现有任务、脚本或其他资源。

## 改动

- App 更新：关于软件入口检查本仓库最新正式 Release，以 versionCode 比较版本；展示发布说明，下载进度及取消/重试。独立网络客户端不携带面板凭据。更新清单限定本仓库 HTTPS 资产，下载大小、SHA256、包名、版本与当前签名全部核对，通过后才打开 Android 安装器。首次授权安装未知来源后，返回点击安装；不静默安装。
- 发布：Actions 测试、签名构建和验签成功后，上传 APK、SHA256SUMS.txt、update.json 到草稿 Release，全部上传成功后公开，避免客户端看到不完整版本。只发布 main，PR 不发布。沿用既有签名，无需 GitHub 登录下载公开 Release。
- 编辑器：CodeMirror 5.65.6 的运行资源随 APK 提供，保留许可证，不再运行时加载 CDN；release 关闭 WebView 调试。新增脚本、编辑脚本和配置三个入口统一未保存返回确认，保存时阻止重复提交，失败保留文本；修改期间提交成功也不丢弃随后输入的文本。
- 多账号：排序使用对象标识，支持同地址和空槽位。只保存排序索引，重启时应用到最新 Token 列表；保存排序后继续登录/退出不会把旧 Token 快照写回来。历史账号按地址、用户名、登录方式区分；旧数据无法唯一匹配时不自动填入不确定的凭据。不记住凭据时仍不保存用户名和密码，空用户名的同地址同模式历史项保持合并。
- 操作：任务、环境变量、依赖批量确认显示面板、数量、名称与 ID，确认前固定对象与原 API 客户端。运行全部快捷入口也需要确认。共享 HTTP 层阻止尚未完成的相同写请求；失败后可手动重试，不自动重放。
- 异常恢复：主要列表刷新失败保留旧数据并提示；依赖操作报告失败。配置文件名编码，应用删除兼容数字 ID；依赖强制删除仅在 404/405 时尝试旧接口，其他失败不再发出第二次删除。

## 验证范围

沿用 `flutter test`，新增更新元数据拒绝异常输入、同地址历史账号、排序与 Token 更新/重启、重复写请求与失败重试、离线编辑器资源及返回确认测试。扩展回环 HTTP 检查环境变量、配置、订阅、依赖和应用接口的路径、参数及响应形状。

Actions 第 10 次运行：10 项测试、签名 APK 构建、验签和公开 Release 发布全部通过。匿名读取更新清单成功；本地下载 APK 的大小和 SHA256 与公开清单一致，Manifest 中包含安装权限和文件共享 Provider，离线编辑器资源及许可证与源码逐文件一致。完整证据见 [BUILD-004.md](BUILD-004.md)。

真机安装器、未知来源授权、真实应用更新到后续版本、WebView 编辑交互、全部业务写操作：NOT_RUN。既有凭据存储加密迁移、完整工具链升级未纳入本轮。

## 集中真机验收

1. 手动覆盖安装首次带更新功能的 APK；检查登录、账号和设置保留。
2. 关于软件 → App 更新：能显示当前版本和检查结果；后续有新版本时检查下载、取消、重试、授权安装、覆盖安装及安装后版本。
3. 登录/切换/退出/重启；同地址不同账号及应用密钥历史项；包含空槽位的排序，保存后退出某个账号再重启，确认顺序和状态正确。
4. 专用测试脚本/配置：输入中文、引号、换行，保存并重新读取；未保存点顶部返回及系统返回均提示；取消离开仍保留内容；断网提交后文本保留。编辑器本身不依赖外网 CDN，读取面板文件仍需要面板连通。
5. 仅用专用测试任务验证新增、运行、停止、启停、日志和删除；检查批量确认面板及对象正确。其他写操作使用隔离测试面板，不用生产数据试验。
6. 列表断网刷新、恢复网络重试、切后台返回与快速切换页面。
